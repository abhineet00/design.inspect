How it works

From that looks off to a prompt it can't misread.

You already know what's wrong. Design.Inspect turns it into exact instructions — so your AI changes what you meant, not what it guessed.

Copy the prompt

You get an exact, element-by-element prompt real selectors like .hero h1 , real values like 18px Prefer to paste it yourself? Copy clean CSS instead.

changes → AI promptCopy
Apply the following design changes to my
web page, then return the updated HTML/CSS.
1. Element `.hero h1`: - set font-size to 72px - set letter-spacing to -0.04em 2. Element `.cta .btn`: - set padding to 16px 30px - set border-radius to 8px
Keep everything else unchanged.
